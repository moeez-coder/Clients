# Query — 2026-09-15 companies snapshot #2 (iVT Expo — Off-Highway Vehicle Technology, expansion)

**Tool:** Blitz API `POST /v2/search/companies`
**Purpose:** Expand this config's company pool before a second Open Check lead push, so the people-search could target companies not already mined in the first round.

**Request body (identical filter to the first 2026-09-15 pull, paginated 14 pages × 50 = 700 raw, from a fresh cursor):**

```json
{
  "company": {
    "industry": {
      "include": [
        "Motor Vehicle Manufacturing",
        "Motor Vehicle Parts Manufacturing",
        "Agriculture; Construction; Mining Machinery Manufacturing",
        "Automotive"
      ]
    },
    "employee_range": ["501-1000", "1001-5000", "5001-10000", "10001+"],
    "hq": { "country_code": ["US", "CA"] }
  },
  "max_results": 50
}
```

**Result:** 700 raw results. Deduped against every company/linkedin_url already in this repo, VNTANA's `dncList`, and the bad-company exclude list. 381 net-new companies written to `2026-09-15-companies-2.csv`. 1,623 total companies match this filter in Blitz — still a partial pull (982 of 1,623 now pulled across both dated files); re-run with a saved cursor to expand further.

**Same caveat as the first pull:** this filter is broader than the actual "off-highway vehicle" niche (Blitz has no off-highway-specific industry value), so it pulls in general Motor Vehicle/Automotive manufacturers — this round's people-search turned up a meaningful number of car dealership groups from this pool, all excluded at the lead level (see the leads `.query.md`/README entry). Worth narrowing this filter in a future company-level pull.
