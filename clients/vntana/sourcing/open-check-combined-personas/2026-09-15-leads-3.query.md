# Query — 2026-09-15 leads snapshot #3 (Open Check "General" — wide-net Aftermarket push)

**Tool:** Blitz API `POST /v2/search/people`
**Purpose:** Large-volume push to the "General \| Open Check" HeyReach campaign (`601752`), sourced specifically from the newly wide-netted VNTANA Aftermarket OEMs segment ("the aftermarket parts catalogue one"), per the repo owner's explicit request for large volume + the widest possible net on that segment.

**Company pool:** the 7,348 net-new companies sourced in `sourcing/aftermarket-oems/2026-09-15-companies.csv` (see that file's `.query.md` for the company-sourcing filter).

**ICP:** Test 1 — Aftermarket 3D Parts Catalog persona from `tracking_clients.get_client` (VP Aftermarket/VP Service primary buyer, CDO exec sponsor, Director Service Operations champion, Director Digital Experience influencer).

**Request body (147 batches of ≤50 company linkedin_urls):**
```json
{
  "company": { "linkedin_url": ["<50 company linkedin_urls per batch>"] },
  "people": {
    "job_level": ["C-Team", "Director", "VP"],
    "job_function": ["Advertising & Marketing", "General Business & Management", "Operations", "Customer/Client Service"]
  },
  "max_results": 50
}
```
`job_function` was widened from prior rounds to include `Operations` and `Customer/Client Service` — the Aftermarket persona (VP Service, Director Service Operations) skews more operations/service-oriented than the marketing-heavy personas targeted in the first two Open Check pushes.

**Result:** 7,350 raw candidates → standard quality-filter pipeline (bad-signal/retired screen, exclude-title-word screen, off-topic-industry screen, relevant-keyword requirement — keyword list extended with `customer service`, `field service`, `technical service`, `warranty`, `spare parts`, `chief digital officer`, `service excellence`, `customer care`, `vp service`, `vp aftermarket`) → 946 qualified → deduped against companies from the client's `dncList` and the running bad-company list.
