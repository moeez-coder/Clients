# Query — 2026-09-15 leads snapshot #4 (Open Check "General" — core-3-segment push)

**Tool:** Blitz API `POST /v2/search/people`
**Purpose:** Large-volume push to "General \| Open Check" (`601752`) sourced specifically from the three segments the repo owner named explicitly: **Industrial Manufacturers, Aftermarket Parts Manufacturer, B2B eCommerce** — i.e. `Industrial Mfg PLM/CAD`, `VNTANA Aftermarket OEMs` (original 99, not the wide-net expansion already fully mined in the prior push), and `VNTANA B2B eCommerce OEMs`.

**Company pool (945 unique companies):**
- `Industrial Mfg PLM/CAD` — both dated files (2026-09-14 + 2026-09-15), 817 companies with native `linkedin_url`.
- `VNTANA B2B eCommerce OEMs` — original 2026-09-10 DiscoLike pull, 71 of 99 rows had a usable `company_linkedin_tag`; reconstructed as `https://www.linkedin.com/company/<tag>`. 28 rows with no tag were skipped (a known gap in the original DiscoLike export — worth a re-pull via Blitz in a future round).
- `VNTANA Aftermarket OEMs` — same treatment on the original 2026-09-10 DiscoLike pull (71 of 99 tagged). The 7,348-company wide-net expansion from the prior push was deliberately *not* re-searched here — it already got a dedicated large-volume pass with the same broadened `job_function` set.

**Request body (19 batches of ≤50 company linkedin_urls):**
```json
{
  "company": { "linkedin_url": ["<50 company linkedin_urls per batch>"] },
  "people": {
    "job_level": ["C-Team", "Director", "VP"],
    "job_function": ["Advertising & Marketing", "General Business & Management", "Operations", "Customer/Client Service"]
  },
  "max_results": 50
}
```
Same broadened `job_function` set as the Aftermarket wide-net push (Operations + Customer/Client Service added) — Industrial Mfg PLM/CAD and B2B eCommerce had previously only been searched with the narrower Marketing + General Business & Management set (in the 2026-09-15-leads.csv round), so this pass was expected to surface real net-new contacts at companies already in the repo, not just re-find the same people.

**Result:** 950 raw candidates → quality-filter pipeline → 123 qualified → deduped against all 867 leads already pushed to any VNTANA HeyReach campaign across all four prior leads files → manual company-level scrub:
- **`Doosan Bobcat` excluded as a DNC match** — this is VNTANA's own existing customer (`tracking_clients.dncList` lists "Bobcat" / `bobcat.com`); the domain field on this lead was blank so it didn't auto-match the DNC domain check, caught on a company-name review instead.
- **`SMS Equipment Inc.` excluded** — a Caterpillar-equipment dealer already on the accumulated bad-company list from earlier rounds, but the automated filter's name-normalization strips periods (`"sms equipment inc."` → `"sms equipment inc"`) while the stored exclude-list entry still has a trailing period, so the automated check missed it. **Known bug, worth fixing the normalization in the shared filter script for future rounds.**
- **`Alta Equipment Company`** — a heavy-equipment dealer, not a manufacturer.
- **`The Boelter Companies`, `Hajoca Corporation`, `OTC Industrial Technologies`** — distributors/wholesalers, not manufacturers.
- **`Integrated Power Services`, `TEAM, Inc.`, `Protolabs`** — service/repair/on-demand-manufacturing bureaus, not OEMs with their own dealer/parts catalog.
- **`Find My Factory`, `Edifice Automotive Marketing`, `Partsimony`, `3D Spark`, `SXP (SolidXperience)`** — a sourcing directory, a marketing agency, a parts-catalog software vendor, and two CAD/3D software companies — none are the target manufacturer.
- **`Tampere University`** — academic institution, off-ICP.
- **`Cargill`** — agribusiness/commodities conglomerate, not a discrete equipment/machinery manufacturer.
- **Company-name fix, not an exclusion:** the six Caterpillar leads came back with the company name in Chinese (`卡特彼勒`) rather than `Caterpillar` — normalized to `Caterpillar` before push so HeyReach/Clay merge-tag personalization renders correctly in English sequences.

**Final: 105 verified leads** across companies including 3M, AGCO, Caterpillar, John Deere, Honeywell, Rockwell Automation, Parker Hannifin, Trane Technologies, Terex, and The Manitowoc Company. **Pushed live to "General \| Open Check" (`601752`)** via `add_leads_to_campaign` in 2 calls (100 + 5); verified via `get_campaign` that `totalUsers` moved 825 → 930, exactly matching accepted counts.
